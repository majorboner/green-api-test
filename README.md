#  Green Api Chat — тестовое задание

Веб-интерфейс для отправки и получения текстовых сообщений в мессенджерах
через сервис [GREEN-API](https://green-api.com/max).

## Локальный запуск проекта

```bash
npm i
npm run dev
```

## Стек

- React 18 + TypeScript
- Vite (сборка и dev-сервер)
- GREEN-API v3 (методы `SendMessage` и `ReceiveNotification`)

## Требования

- Node.js 18 или выше
- npm (или pnpm / yarn)
- Аккаунт GREEN-API с авторизованным инстансом
